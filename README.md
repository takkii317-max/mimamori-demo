# はたけみまもり(試作・画面イメージ)

SAGA IGNITE 中間発表(2026年10月25日)で、ポスターセッションの来場者に触ってもらうための試作です。アプリとして動くものではなく、画面と動きのイメージを見せるものです(実際の位置の取得や通知は動きません)。

> 農家の安心をつくる、もしもに気づけるつながり

- 人物・自宅・畑・記録はすべて架空です。位置や通知は実際には動きません。
- 地図は実在の地域(佐賀県白石町付近)を使っています。

## 使い方

1. はじめの画面で「農家として使う」か「見守る側として使う」を選びます。
2. 右下の「デモ」から時間を進めます。「次の出来事へ」で、出発・到着・知らせなどの場面まで一気に進みます。
3. デモ操作の中で、1日の流れを4つから選べます。
   - いつもの1日:作業開始を押して出発し、夕方に帰宅する
   - 押し忘れた日:作業開始を押さずに出発。自動で記録が始まる
   - 帰りが遅い日:夕方に電波が途絶え、帰宅の目安を過ぎる → 通知 → 反応がなければSMS
   - 長く動かない日:スマホを持ち歩いていて、畑で動きが止まる → 本人に「大丈夫ですか?」 → 応答がなければ家族に通知
4. 「見守る側へ/農家側へ」で、同じ1日を反対側の画面から見られます。

スマホでは、ブラウザの「ホーム画面に追加」をすると、アプリのように全画面で開けます。

## 公開のしかた(GitHub Pages)

リポジトリの Settings → Pages → Build and deployment で、Source を「Deploy from a branch」、Branch を「main」「/ (root)」にして Save します。数分後に `https://<ユーザー名>.github.io/mimamori-demo/` で開けるようになります。
